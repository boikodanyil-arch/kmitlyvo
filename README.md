# Кмітливо (бета)

Простір для репетиторів і онлайн-шкіл англійської: розклад, учні, домашні завдання з фото, квізи з автоперевіркою, оплати та кабінет учня.

- Статичний сайт (HTML + JS модулі, без збірки), хостинг GitHub Pages.
- Бекенд: Supabase (Postgres + RLS + Storage + edge function `auth-signup`).
- Дизайн-система: `assets/styles.css`, гайд: `design-guide.md`. Інструкція для розробки: `BUILD.md`.
